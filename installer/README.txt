Instant Karma v@@VERSION@@
Mods for Shin Megami Tensei: Digital Devil Saga (USA, SLUS-20974) on PCSX2 2.x.

This package contains no game data. You need your own copy of the game.

INSTALL
  1. Extract this zip to any folder.
  2. Close PCSX2.
  3. Run Install.bat.
  4. Choose your game's disc image, check the PCSX2 folder it found, pick the modules you want, and click Install.
  5. Start the game in PCSX2. To change modules later, run Install.bat again, or use PCSX2:
     right-click the game > Properties > Patches.
     Keep "Instant Karma - Core" ticked whenever any other module is on.

With Native Turbo on, the installer also sets EE Cycle Rate to 300% for this game (needed for full 6x);
the earlier value comes back if Native Turbo is turned off or Instant Karma is removed.
Mods are loaded by PCSX2 when the game boots. PCSX2's achievements hardcore mode turns patches off.
Savestates keep the mods that were on when they were made; after changing modules, load from a memory card save.

UNINSTALL
  Run "Uninstall Instant Karma.bat" in the instantkarma folder inside your PCSX2 data folder, or click Remove in the
  installer. Only what Instant Karma added is removed.
